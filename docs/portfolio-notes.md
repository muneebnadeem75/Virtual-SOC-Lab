# Portfolio Notes

This repository is a portfolio presentation of an academic Virtual SOC laboratory.

## Source Material

The repository was prepared from the project report and selected screenshots from the lab evidence.

## Deliberately Excluded

- Original university report
- Student number and personal identifiers
- Password lists and credentials
- Private/internal IP addresses where unnecessary
- Session/request tokens
- Raw academic submission material
- Claims of production-scale SOC performance

## Repository Scope

This is a documentation/evidence repository. It does not claim to contain the original VM images, Wazuh configuration files, custom detection rules or source code.
