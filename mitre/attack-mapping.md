# MITRE ATT&CK Mapping

| Lab Activity | ATT&CK Mapping | Purpose |
|---|---|---|
| SSH password guessing | **T1110 – Brute Force** | Represents repeated attempts to obtain valid credentials through password guessing. |
| Persistence-related configuration modification | **TA0003 – Persistence** | Represents configuration changes that could support maintaining access after compromise. |
| SQL injection against DVWA | **T1190 – Exploit Public-Facing Application** | Represents exploitation of a vulnerable web application. |

## Notes

The mappings are used as an analytical framework for describing the controlled laboratory activity. They do not imply that the lab reproduced a complete real-world intrusion chain.
